# АгроМаркет API — лабораторные работы 5–6

## Требования
- Node.js 18.11+
- PostgreSQL 16/17
- npm

## Первый запуск
1. Создайте в PostgreSQL базу `agromarket`.
2. В этой папке выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и укажите свой пароль PostgreSQL в `DATABASE_URL`.
4. Выполните `npm run db:init` — создадутся таблицы и загрузятся демонстрационные товары.
5. Выполните `npm run dev`.
6. Запустите frontend из папки `agromarket-react`: `npm install`, затем `npm run dev`.

Не добавляйте `.env` в Git: в нём хранится пароль.

## Эндпоинты
| Метод | Путь | Описание | Ответы |
|---|---|---|---|
| GET | `/` | Проверка сервера | 200 |
| GET | `/api/health` | Проверка API и БД | 200, 500 |
| GET | `/api/about` | Информация об API | 200 |
| GET | `/api/products` | Каталог, параметры `search`, `maxPrice`, `sort` | 200, 400 |
| GET | `/api/products/:id` | Один товар | 200, 400, 404 |
| POST | `/api/products` | Создать товар | 201, 400 |
| PUT | `/api/products/:id` | Обновить товар | 200, 400, 404 |
| DELETE | `/api/products/:id` | Удалить товар | 204, 400, 404 |
| GET | `/api/orders` | Заявки с названием товара | 200 |
| POST | `/api/orders` | Создать заявку | 201, 400 |
| PATCH | `/api/orders/:id` | Изменить статус заявки | 200, 400, 404 |

## Примеры запросов
Каталог: `GET http://localhost:3000/api/products`
Поиск: `GET http://localhost:3000/api/products?search=мол`
Фильтр цены: `GET http://localhost:3000/api/products?maxPrice=1000`
Сортировка: `GET http://localhost:3000/api/products?sort=-price`

Создать товар (`POST /api/products`, JSON):
```json
{"name":"Морковь, 1 кг","category":"Овощи","price":500,"unit":"кг","image":""}
```

Создать заявку (`POST /api/orders`, JSON):
```json
{"name":"Тестовый покупатель","email":"test@example.com","phone":"+77001234567","quantity":10,"delivery_date":"2026-10-20","comment":"Тест"}
```

## Ответы для отчёта

### Лабораторная 4
1. Box model состоит из content, padding, border и margin. Конкретные размеры нужно снять в DevTools на запущенной карточке; они зависят от ширины окна и CSS.
2. При `box-sizing: border-box` заданная ширина включает content, padding и border. Без него padding и border добавляются к ширине content.
3. Семантические элементы `header`, `nav`, `main`, `section`, `aside`, `footer` понятнее описывают назначение блоков, чем набор безымянных `div`.
4. Flexbox используется для размещения элементов в одном направлении (шапка, панель поиска, содержимое карточки); Grid — для сетки карточек и общего макета.
5. Адаптивность проверяется на ширине примерно 375 px, 768 px и 1280 px. Mobile-first означает, что базовые стили рассчитаны на узкий экран, а дополнительные правила добавляются через media queries.
6. Форма использует `email`, `tel`, `number`, `date` и `required`; поле количества ограничено `min="10"`.

### Лабораторная 5
- `res.send()` обычно возвращает текст с `Content-Type: text/html; charset=utf-8`, а `res.json()` — JSON с `Content-Type: application/json; charset=utf-8`.
- Неизвестный маршрут без обработчика 404 возвращает стандартный ответ Express 404.
- Middleware — функция обработки запроса; без `next()` и без отправки ответа запрос зависнет.
- Логгер должен быть подключён до маршрутов, чтобы видеть запросы ко всем endpoint.
- Без `express.json()` Express не разбирает JSON-тело, поэтому `req.body` не будет содержать ожидаемые поля.
- Проверка на сервере обязательна: клиентские ограничения можно обойти прямым HTTP-запросом.
- Использование ИИ: помощь в создании структуры проекта, проверке кода и подготовке ответов; код необходимо запустить и проверить самостоятельно.

### Лабораторная 6
- `price = -5` отклоняется серверной проверкой и ограничением `CHECK (price >= 0)`.
- Отсутствие `name` отклоняется проверкой обязательных полей и `NOT NULL`.
- Несуществующий `product_id` отклоняется внешним ключом; API возвращает понятную ошибку 400.
- SQL-инъекция не выполняется, потому что пользовательские значения передаются параметрами `$1`, `$2`, а не склеиваются с SQL.
- Проверка `quantity >= 10` на сервере даёт понятное сообщение, а `CHECK (quantity >= 10)` защищает базу при запросах в обход API.
- После удаления товара заявки сохраняются, а `product_id` становится `NULL` благодаря `ON DELETE SET NULL`.
- Для паролей и секретов используется `.env`, который исключён из Git.

## Важно перед сдачей
- Замените «Укажите своё ФИО» в `/api/about`.
- Впишите ФИО, группу и дату в отчёт, если преподаватель требует отдельный титульный лист.
- Размеры box model, фактические статусы запросов, скриншоты DevTools и результаты запуска добавьте после проверки на своём компьютере.
